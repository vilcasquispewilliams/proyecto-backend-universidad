# PA3 - Proyecto Backend Universidad

## Microservicios Node.js + SQL Server

### 1. Microservicio-Estudiantes - Puerto 3001
CRUD completo de estudiantes usando Express y SQL Server
Pruebas automatizadas con Jest y Supertest

### 2. Microservicio-Cursos - Puerto 3002  
CRUD completo de cursos usando Express y SQL Server
Pruebas automatizadas con Jest y Supertest

## Instalación y ejecución
```bash
# Estudiantes
cd Microservicio-Estudiantes
npm install
npm start

# Cursos
cd Microservicio-Cursos
npm install
npm start
